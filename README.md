# rclone-oauth

Static pages required by Google to publish the OAuth consent screen of a personal Google Cloud project.

The project lets [rclone](https://rclone.org) access my own Google Drive with a dedicated client ID instead of the shared default one. It is used only by me.

This repository contains no code, credentials or configuration:

- `index.html`: the application home page
- `privacy.html`: the privacy policy

Published at https://n0sum.github.io/rclone-oauth/
